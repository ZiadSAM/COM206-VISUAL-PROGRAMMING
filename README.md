# Taskflow

Taskflow is a simple to-do list application made for my Visual Programming midterm project.

## Features
- Add new tasks
- Mark tasks as completed
- Delete all tasks from settings
- Confirmation dialog before deleting all tasks
- Settings page
- Version display

## Technologies Used
- Flutter
- Dart

## Project Structure
- `main.dart` → contains the main app logic, task model, home page, and settings page

## How It Works
- Users can add a task using the + button
- Tasks are displayed in a list
- Each task has a checkbox to mark it as completed
- The settings page allows deleting all tasks
- A confirmation dialog appears before deleting all tasks

## Installation
- Clone the repository:
  git clone https://github.com/ZiadSAM/COM206-VISUAL-PROGRAMMING
  
- Navigate to the project folder:
  cd COM206-VISUAL-PROGRAMMING/submissions/ziyad-sobhi
  
- Install dependencies:
  flutter pub get
  
- Run the application:
  flutter run

# Student Grading System

A desktop GUI application developed using Python, PySide6, and Qt Designer.

## Features
- Enter student information and grades
- Calculate weighted final score
- Determine letter grade
- Display pass/fail status
- Add records to a table
- Delete selected records
- Clear input fields
- Input validation with popup messages

## Technologies Used
- Python
- PySide6
- Qt Designer

## How the Application Works
1. Enter student name and course name
2. Enter midterm, final, and homework grades
3. Press the Calculate button
4. The application calculates:
   - Final score
   - Letter grade
   - Pass/fail status
5. Press Add to Table to save the record

## Grade Calculation Formula

Final Score =  
(Midterm × 30%) + (Final × 50%) + (Homework × 20%)

## Installation

1. Clone the repository
git clone https://github.com/ZiadSAM/student-grading-system.git

2. Open the project folder
cd student-grading-system

4. Install required libraries
pip install PySide6

5. Run the application
python main.py

## Requirements

- Python 3.x
- PySide6
- Qt Framework
